# Mei Wong - Software Developer Portfolio

This project is a responsive portfolio website for Mei Wong, a software developer. It is designed to introduce Mei to potential employers and clients, showcase her skills and previous projects, and provide visitors with ways to connect with her. The website includes an About section, a portfolio of projects, a newsletter subscription feature, and a contact form. It was built using HTML, CSS, and Bootstrap, with responsive design techniques to provide a good user experience across different screen sizes.

## Features

- Responsive navigation bar
- Hero section
- About section
- Portfolio section showcasing projects
- Newsletter subscription modal
- Contact form

## Technologies Used

- HTML5 - used to structure the content of the website.
- CSS3 - used for custom styling.
- Bootstrap 5 - used for responsive layouts, components, and utility classes.

## Testing
The website was manually tested to ensure that:

- The navigation links work correctly.
- The layout is responsive across different screen sizes.
- The newsletter modal opens and closes correctly.
- The contact form fields can be completed.
- The portfolio cards display correctly.
- Buttons and links work as expected.

## Deployment
This website was deployed using GitHub Pages.

To deploy the project:

1. Navigate to the repository on GitHub.
2. Go to **Settings** and select **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the **main** branch and **/(root)** folder.
5. Click **Save**.
6. Once the deployment is complete, the live website can be accessed through the link provided by GitHub Pages.
